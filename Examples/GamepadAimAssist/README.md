# 手柄辅助瞄准

适用于《开拓物语》支持 SDK v1 的 Windows x64 Mono 测试版。准备一把能显示远程准星的武器和一个手柄。

1. 在开始界面打开「模组 → 本地模组 → 复制路径」，在资源管理器打开该目录。
2. 将成品 ZIP 解压到这里，确认文件位于 `Mods/gamepad-aim-assist/manifest.json`。重新打开模组管理，勾选「手柄辅助瞄准」，退出整个游戏并重开。
3. 用手柄打开「设置 → 游戏」，用十字键向下，从自动拾取品质走到「辅助瞄准强度」。左右每次调整 5%，选中时也可按 LT / RT。继续向下可进入底部操作区，再向上可返回。新安装默认 50%，升级沿用本机设置。
4. 在测试存档装备远程武器，找一只可见、与角色之间没有障碍的怪物。在 0% 和 100% 各试一次：让准星停在怪物旁边，松开右摇杆，轻扣开火。100% 时，第一发取点前准星会吸到怪物身上；0% 时准星仍停在原处。高强度下如果准星周围没有候选，松杆开火还会查找角色身边的近敌。推杆离开可脱离。武器原有散布和后坐力仍参与射击。
5. 要投稿，测试者用自己的 Steam 账号启动游戏，到「模组 → 本地模组」选中作品，点「发布到创意工坊」。首次测试可选「私有」，确认上传后点「查看工坊页面」，核对作者与作品编号。该测试账号以后用同一台电脑、同一模组 ID 再投稿，会更新自己的作品。

已有旧版的本地作者请退出游戏，用 1.0.2 覆盖原来的同名模组文件夹。验证订阅自动升级时，请由首次投稿的账号在原投稿环境更新同一作品，让另一个账号保留订阅观察。另一个账号单独投稿会创建该账号自己的作品。

**验证设备切换**：先用键鼠打开游戏设置，辅助瞄准强度应隐藏。改用手柄，选中该行并调到 65%，再用键鼠操作，确认该行隐藏，焦点离开滑条。切回手柄后，从「自动拾取品质」向下应只经过一条辅助瞄准设置，数值仍为 65%。在其他设置项或弹窗上切换设备时，模组会保留当前选择。

要验证语言切换，把游戏语言从简体中文切到英文，同一行应从「辅助瞄准强度」变为 **Aim assist strength**，已选百分比保持原值。实现见 [AimStrengthRow.ShowValue](Source/AimStrengthRow.cs)，自己的模组可以按[多语言指南](../../Reference/模组多语言.md)选择支持的语言。

## 修改与编译

在本示例目录运行，替换为自己含 `FrontierTale.exe` 的安装目录。

```shell
dotnet build Source/GamepadAimAssist.csproj -c Release "-p:GameDir=D:/SteamLibrary/steamapps/common/FrontierTale"
```

输出位于 `ReleaseExample/gamepad-aim-assist`，内含 DLL、清单和封面。模组使用 SDK v1 生命周期，准星写入方法和设置页滑条来自游戏 2.1.6。游戏更改该方法签名或设置页层级时需重新核对。
