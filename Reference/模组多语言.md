# 模组多语言指南

**多语言是可选项。** 作者只写一种语言，就按原文显示。例如，按钮写成「整理背包」，英文玩家看到的也是「整理背包」。单语言模组照常安装、启用和投稿。

## 模组列表里的名称与描述

在 `manifest.json` 的 `title` 和 `description` 填写希望玩家看到的文字。当前清单格式中，这两个字段各接受一个字符串。本地模组列表直接显示这组文字。想同时展示两种语言，可以自己在字符串里并列填写。

## 让设置项或窗口跟随游戏语言

C# 模组可以自带译文。先选定自己作品的默认语言，再为希望支持的语言提供文字。例如，下面的设置项以中文为原文，额外支持英文。把这个方法放进控件类，在首次显示以及游戏语言改变时用它更新标签。

```csharp
using V.Framework;

// 为当前游戏语言选择标签文字，其余语言沿用作者写的中文原文。
private static string GetSortButtonLabel()
{
    return LocalizationManager.Instance.CurrentLanguage switch
    {
        GameLanguage.English => "Sort inventory",
        _ => "整理背包"
    };
}
```

游戏提供 `SimplifiedChinese`、`TraditionalChinese`、`English` 和 `Japanese` 四种语言。默认显示哪种文字由作者决定。手柄辅助瞄准示例在设置行首次显示时读取当前语言，界面打开期间仅在语言改变时重设标签。按钮文字可以变化，强度百分比仍读取同一个设置值。[查看设置行源码](../Examples/GamepadAimAssist/Source/AimStrengthRow.cs)

## 在游戏里验证

1. 启用自己的模组并重启游戏，打开模组提供的界面，核对原文。
2. 在「设置 → 游戏」切换到有译文的语言，再看同一控件。例如上面的按钮，英文应显示 **Sort inventory**。
3. 切换到未提供译文的语言，例如上例中的日文，按钮应显示作者选定的默认文字「整理背包」。如果只做单语言，切换前后都应显示原文。
